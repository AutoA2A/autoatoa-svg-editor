## SVG 在线编辑器

这是一个由多个 AI 协作完成的 SVG 在线编辑器项目，提供了一个完整的网站，允许用户在线创建、编辑和保存 SVG 图形。

## 网站简介

SVG 在线编辑器旨在为用户提供一个便捷的在线平台，用于创建和编辑 SVG 图形。该网站提供了丰富的功能，包括图形绘制、编辑、保存和导出等，满足用户对 SVG 图形处理的需求。

## 页面与功能

网站包含 8 个页面，主要功能如下：

* 首页：介绍 SVG 在线编辑器的功能和特点，提供快速入口链接到编辑器页面。
* 编辑器页面：提供 SVG 图形编辑功能，包括图形绘制、编辑和保存等。
* 图形库页面：展示预设的 SVG 图形库，方便用户直接使用或参考。
* 教程页面：提供 SVG 编辑器使用教程和 SVG 相关知识，帮助用户快速上手。
* 关于页面：介绍 SVG 在线编辑器的开发团队和项目背景。
* 帮助页面：提供常见问题解答和联系方式，方便用户获取帮助。
* 导出页面：提供 SVG 图形的导出功能，支持多种格式。
* 错误页面：处理访问错误或页面不存在的情况，提供友好的错误提示。

## 多 AI 协作与验收

本项目采用多 AI 协作的方式完成，多个 AI 模型共同参与了网站的设计、开发和测试。协作流程包括：

1. 需求分析和设计：AI 模型根据项目需求进行网站设计和功能规划。
2. 页面开发：多个 AI 模型分别负责不同页面的开发，实现网站的功能。
3. 测试和验收：AI 模型进行自动化测试和交叉验收，确保网站的稳定性和功能完整性。

## GitHub Pages 部署与访问

本项目已部署到 GitHub Pages，入口文件为 `index.html`。用户可以通过访问 `https://<用户名>.github.io/<仓库名>` 来访问 SVG 在线编辑器网站。具体步骤如下：

1. 打开 GitHub 仓库页面。
2. 进入仓库的 `Settings` 页面。
3. 找到 `GitHub Pages` 部分，选择 `main` 分支作为发布源。
4. 访问 `https://<用户名>.github.io/<仓库名>/index.html` 即可进入 SVG 在线编辑器网站。

现在，您可以访问 SVG 在线编辑器网站，体验在线创建和编辑 SVG 图形的便捷。
