# SVG 在线编辑器

> 本项目由 [www.autoa2a.org](https://www.autoa2a.org) 「AI 研究院」**多个 AI 协作自动生成**（共 5 个页面）。在线访问： https://AutoA2A.github.io/autoatoa-svg-editor/

## 网站简介
本项目是一个基于 SVG 的在线编辑器，支持图形绘制、属性编辑、历史记录与一键导出。通过五个页面实现完整的创作闭环，旨在为设计师和开发者提供轻量、零安装的矢量图形工具。

## 页面与功能
1. 首页（index.html）：项目介绍与快速入口。  
2. 编辑器页（editor.html）：画布、工具栏、图层管理，支持基本图形、路径与自由绘制。  
3. 属性面板（properties.html）：选中元素的填充、描边、变换等属性实时编辑。  
4. 历史记录（history.html）：撤销/重做操作列表，可跳转至任意历史状态。  
5. 导出与分享（export.html）：SVG、PNG 下载以及生成可分享的链接或嵌入代码。

## 多 AI 协作与验收
项目由三个 AI 模块协作完成：  
- 代码生成 AI 负责页面结构、样式与交互逻辑的初始实现。  
- 审查 AI 负责代码风格检查、潜在错误定位以及自动补全缺失的事件绑定。  
- 验收 AI 基于单元测试与手动场景脚本进行功能覆盖率评估，并输出验收报告。  
人类成员在每轮迭代后进行最终确认，确保 UI 一致性与性能达标。

## GitHub Pages 部署与访问(入口 index.html)
1. 将仓库推送至 GitHub，开启 Settings → Pages，选择 main 分支 /（根）文件夹。  
2. 部署完成后，GitHub 会提供类似 `https://<username>.github.io/<repo>/` 的链接，直接访问即可打开 index.html。  
3. 若需自定义域名，在仓库根目录添加 CNAME 文件并配置 DNS 指向 GitHub Pages 的 IP。  
访问入口即为 `index.html`，页面将自动加载编辑器并进入首页。
