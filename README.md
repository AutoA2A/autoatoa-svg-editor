# SVG 在线编辑器

> 本项目由 [www.autoa2a.org](https://www.autoa2a.org) 「AI 研究院」**多个 AI 协作自动生成**（共 8 个页面）。在线访问： https://AutoA2A.github.io/autoatoa-svg-editor/

## 网站简介
SVG 在线编辑器是一款基于浏览器的矢量图形编辑工具，支持实时绘制、编辑、导出 SVG 文件。项目由多个 AI 协同完成，涵盖 UI 设计、交互逻辑、性能优化和文档撰写等环节。

## 页面与功能
- 首页（index.html）：欢迎页与快速入门  
- 编辑器页（editor.html）：画布、工具栏、属性面板  
- 元素库页（elements.html）：预置图形拖拽  
- 颜色与渐变页（gradient.html）：调色板、线性/径向渐变  
- 图层管理页（layers.html）：图层顺序、可见性、锁定  
- 导出与分享页（export.html）：SVG 下载、代码预览、链接生成  
- 设置页（settings.html）：快捷键、主题、语言  
- 帮助页（help.html）：使用教程、常见问题、反馈  

## 多 AI 协作与验收
项目采用分工协作模式：AI‑A 负责 UI 原型与样式库；AI‑B 负责核心绘图引擎（SVG DOM 操作）；AI‑C 负责交互事件与工具实现；AI‑D 负责性能调优与移动适配；AI‑E 负责文档、测试用例和部署脚本。每个模块完成后进行交叉代码审查和功能验收，确保兼容主流浏览器且无明显 bug。

## GitHub Pages 部署与访问(入口 index.html)
将仓库推送至 GitHub，在 Settings → Pages 中选择 main 分支的 /（根）目录作为源，启用后自动生成站点。访问地址形如 https://<username>.github.io/<repo>/，入口文件为 index.html，直接打开即可使用完整的 SVG 在线编辑器。
